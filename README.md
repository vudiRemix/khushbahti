# Хаос-Доска

Браузерная игра для ПК по мотивам мем-картинки, где на одной шахматной доске смешались десяток игр.
Шахматы, «Сапёр», CS, Minecraft, GTA, Plants vs. Zombies, FNAF, Clash Royale, Pac-Man, PUBG и Google-змейка
здесь не просто нарисованы: у каждой есть своя механика.

## Как запустить

**Самый простой способ:** открой `dist/khaos-doska.html` в Chrome, Edge или Firefox.
Это один файл, его можно скопировать куда угодно или отправить другу.

Или открой `index.html` из корня проекта: это та же игра, разбитая на модули в папке `js/`.

Нужен только браузер. Ничего устанавливать не нужно. Звук включается после первого клика.

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ (зажать) | стрелять из АК-47 |
| ПКМ | закинуть удочку: открыть клетку сапёра, подобрать предмет или солнце, посадить фигуру |
| F, Пробел или колесо (клик) | поставить или снять флажок |
| R | перезарядка |
| 1–9 или клик по слоту | использовать предмет из хотбара |
| Колесо мыши, E | выбрать слот / использовать выбранный |
| Q | выбрать фигуру для посадки (пешка / слон / ладья) |
| Shift (держать) | замедление времени, тратит зелёную шкалу «буст» |
| Esc или P | пауза |
| M | звук вкл/выкл |

## Цель

Разрушь **башню короля** наверху доски.

- Король стреляет **ядрами прямо в экран**. Сбей ядро, пока не долетело: красный круг показывает, куда оно упадёт.
- В центре доски лежит поле **«Сапёра»**. Открывай клетки удочкой (ПКМ). За каждую дают деньги, патроны, опыт, а иногда предмет.
- **Флажок на настоящей мине становится ловушкой**: враг, который на неё наступит, взорвётся.
- **Открой все безопасные клетки**, и оставшиеся мины полетят ракетами в башню (35 урона каждая). Потом поле собирается заново, и мин становится больше.
- Ошибся и подцепил мину удочкой? Взрыв, минус 5 HP.

## Кто есть кто

| Отсылка | Что делает в игре |
|---|---|
| **Шахматы** | Чёрные фигуры — враги и ходят по правилам: пешка идёт вперёд и бьёт наискосок, конь прыгает буквой «Г», ладья ездит по прямой, слон по диагонали. Белые фигуры внизу — твоя оборона. Белая пешка бьёт врагов на соседних клетках по диагонали |
| **Сапёр** | Поле с минами, флажки-ловушки, «аккорд» (ПКМ по числу открывает соседей, если вокруг стоит нужное число флажков), табло с минами, таймером и смайликом |
| **CS** | АК-47 в руке: отдача, разброс при стрельбе очередью, перезарядка, счётчик патронов в углу |
| **Minecraft** | Сердечки, голод (надо есть стейки), опыт и уровни (каждый уровень +3% к скорострельности), хотбар на 9 слотов, удочка, тотем бессмертия |
| **GTA** | Часы, полоска здоровья, деньги `$00000000`, звёзды розыска (больше звёзд — больше и сильнее врагов), экраны **WASTED** и **MISSION PASSED** |
| **Plants vs. Zombies** | Зомби и зомби с конусом едят твои фигуры. С неба падает солнце (лови удочкой), за солнце сажаешь новые фигуры: пешку (50), слона-стрелка (100), ладью-стену (125) |
| **FNAF** | Игровые часы идут, в полночь наступает ночь: темнота и фонарик вокруг прицела. Приходит **Золотой Фредди**: он телепортируется к тебе, и если не успеть его убить, будет скример. В 6 AM ночь заканчивается |
| **Clash Royale** | Королевская башня — главный босс: полоска HP с короной, король смеётся «Хе-хе-хе!», в ярости зовёт подкрепление, при победе даёт три короны |
| **Pac-Man** | Стоит слева у последнего ряда и работает как газонокосилка из PvZ: когда враг доходит до твоих фигур, Пак-Ман проносится по ряду и съедает всех. Предмет «энерджайзер» отправляет его в ряд, где больше всего врагов |
| **PUBG** | Аирдроп на зелёном парашюте с красным дымом (подцепи удочкой: внутри 3 предмета). Синяя шкала — броня, зелёная — буст |
| **Google-змейка** | Синяя змейка ползёт по рядам, ест предметы на доске и от этого растёт |
| **Кубик** | Случайный эффект от 1 до 6: от неудачи (+звезда розыска) до авиаудара по башне и джекпота |

## Предметы (хотбар)

1. **Стейк**: +8 к сытости
2. **Золотое яблоко**: +6 HP, +20 брони
3. **Зелье лечения**: +10 HP
4. **Динамит**: бросок в точку прицела, взрывает врагов и вскрывает клетки 3×3
5. **Кубик**: случайный эффект
6. **Патроны 7.62**: +90 патронов
7. **Лёд**: замораживает всех врагов на 5 секунд
8. **Энерджайзер**: Пак-Ман выходит на охоту
9. **Тотем бессмертия**: срабатывает сам, когда тебя убивают

## Как устроен проект

Чистый JavaScript и Canvas, без движков и без сборщиков. Вся графика нарисована кодом,
звуки синтезируются через WebAudio, внешних картинок и аудиофайлов нет.

```
index.html        — страница игры
js/core.js        — константы, настройки баланса (CFG), утилиты, ввод
js/audio.js       — синтезатор звуков
js/art.js         — рисование всех персонажей, предметов и элементов интерфейса
js/board.js       — шахматная доска и логика «Сапёра»
js/entities.js    — враги, белые фигуры, Пак-Ман, предметы, аирдроп, ядра
js/game.js        — правила игры: стрельба, удочка, волны врагов, день и ночь
js/render.js      — отрисовка кадра, интерфейс и экраны
js/main.js        — запуск, масштабирование окна, обработка мыши и клавиатуры
tools/build.mjs   — сборка всего в один файл dist/khaos-doska.html
```

### Баланс

Все основные числа лежат в объекте `CFG` в `js/core.js`: здоровье башни, урон мин,
скорость дня, патроны и так далее. Поменяй и обнови страницу.

### Сборка одного файла

После правок в `js/` пересобери `dist/khaos-doska.html` (нужен Node.js 18+):

```
npm run build
```
